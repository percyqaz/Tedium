# Tedium

Is a terminal-based todo list made to fit in with several other terminal-based tools I use daily  
Designed for my personal use and I have now consistently used it for a couple of months

- Todo lists are text files, items to do marked with a `*`, and `x` if complete
- Nested items supported, items can have arbitrary text/descriptions/front matter
- Items can have tags denoted by `@`
- Vim-like keybinds

Likely future features
- Reading and writing to Google Calendar
- Reading and writing to Github Issues via Github's CLI

## Installing

1. Clone the repo

2. Run `./update.sh` to install as a dotnet tool  
   Needs dotnet 10 installed and googling skills for when your dotnet tools are inevitably not found in your path

3. Run with `tedium`
